About SuPoku

SuPoku is a Pokémon trivia game built around a three-by-three grid. Each row and column has a clue. Your job is to find a Pokémon that belongs to both, using nine guesses to complete the board.

A small puzzle with room to think

The challenge is making connections across what you know: types, regions, moves, evolution, stats and forms. A familiar answer can get you started; remembering an unusual one can make a square especially satisfying. Each Pokémon can be used only once, so an answer that fits several squares is worth saving for the trickier intersection.

Daily mode offers a date-based puzzle. Random mode gives you another grid whenever you want to practice. Each square starts with a free retry, and one undo lets you reconsider a decision during the game.

How the answers are chosen

The game checks answers against its bundled Pokédex dataset, based on PokeAPI data. Categories are matched before a grid is shown so that each square has multiple possible answers. Forms are separate entries when their game data differs. The rules page explains several details that can affect an answer.
